# DreamWorks 使用指南与技术说明

> 把「看见屏幕、看见你、把想法画出来、把会开完」收进一个窗口——录屏、圆形摄像头画中画、白板与在线会议一体完成。

---

## 开始之前：30 秒 Brief

| 它是什么 | 一台 Mac 上的**桌面应用**（Electron），主打**演示与录制体验**：屏幕 + 摄像头 + 白板 +（可选）局域网会议，少切窗口、少装一堆单功能工具。 |
|---------|----------------------------------------------------------------|
| 你最常这样用 | **录课 / 做教程**：抓屏 → 开摄像头画中画 → 需要时拉白板标注 → 一键录制导出。**开会**：Live Meeting，同一 Wi-Fi 下可走局域网模式，不依赖付费云会议。**口播**：提词器 + 美颜，对着镜头说清楚。 |
| 不适合谁 | 追求「几 MB 极简安装包」的纯工具党（本应用是完整桌面壳）；需要跨平台 Windows/Linux 正式支持的用户（当前以 macOS 为主）。 |

**一句话**：如果你厌烦「OBS 调半天 + 再开一个画图 + 再开一个会议链接」，DreamWorks 用**一条短路径**把演示链路串起来。

---

## 为什么要有 DreamWorks（故事）

很多人都有过这样的下午：要录一段操作演示，先打开录屏，再想办法把摄像头叠在画面上；讲到一半想画个箭头，又切到另一个白板或截图标注工具；团队临时对齐，还要再复制一个会议链接、担心云录制额度或数据出内网。

工具本身都没错，错的是**上下文被切碎**——你的注意力在窗口之间跳来跳去，观众或同事却在等你把画面和讲解对齐。

DreamWorks 的起点很简单：**预览区里同时装下屏幕、圆形画中画摄像头和白板**，录制与会议都在同一套控制逻辑里。我们不是替你做「更重的剪辑台」，而是让你在**讲解、标注、出镜、开会**这几件事上，少几次「等一下我切一下软件」。

## 谁的痛点？为什么用 DreamWorks？

下面按**典型用户**对齐**痛点**和**本产品能补上的那一环**（详细操作见后文各章节）。

| 你是谁 | 你可能卡在哪里 | DreamWorks 想解决什么 |
|--------|----------------|----------------------|
| **讲师 / 培训师 / 内部培训** | 录课时要屏幕 + 出镜 + 板书，多软件切换容易断节奏、后期对齐费时 | **同屏预览 + 白板分层（底图 + 注释层）+ 录制合成**，一条工作流讲完 |
| **产品经理 / 设计师 / 售前** | 演示原型时要边讲边画流程，会议里还要共享屏幕，工具分散 | **白板（Excalidraw）与屏幕捕获同一窗口**，Live Meeting 内屏幕共享与讨论 |
| **内容创作者 / UP 主** | 教程口播容易忘词，镜头观感要快速美化，导出要清晰 | **提词器**、**美颜与装饰**、多档**分辨率与截图预设**（封面/头像等） |
| **小团队 / 对数据敏感的组织** | 不想为每次短会付云订阅，或希望流量不出内网 | **Live Meeting 局域网模式**：同一 Wi-Fi 内建房间、分享地址即可，无云信令依赖（详见会议章节） |
| **会议主持人** | 需要聊天、录制、虚拟背景、转写等「全套会议能力」但希望和演示工具离得近 | **Live Meeting** 提供常见会议能力，并与主应用的捕获/白板场景衔接 |

**快速对照**（与上表一致，便于检索）：

| 用户类型 | 典型场景 | 推荐功能组合 |
|---------|---------|-------------|
| 远程教学 / 培训师 | 讲屏幕、画图、录课 | 录屏 + 白板 + 摄像头画中画 |
| 产品经理 / 设计师 | 原型演示、流程图、讨论 | 白板 + Live Meeting + 屏幕共享 |
| 内容创作者 | 教程、口播 | 录屏 + 提词器 + 美颜 |
| 团队协作 | 同网段免费会、少上云 | Live Meeting（Local） |
| 会议主持人 | 视频会议与录制、转写 | Live Meeting 全功能 |

## 怎么用：三条最短路径

不必一次学完所有按钮，先选一条路径跑通：

1. **录一段带讲解的视频**  
   **Capture Screen**（或 **Start Camera** 至少其一）→ 需要时打开 **Whiteboard** 标注 → **Start Recording** → **Stop** 后选路径导出 WebM / MP4。

2. **开一场会**  
   点 **Live Meeting** → 填昵称与房间 → 选 **Cloud** 或 **Local**（局域网）→ **Join**；会内可开关音视频、共享屏幕、聊天、录制等（见下文 §2.7）。

3. **只画画或只准备口播**  
   打开 **Whiteboard** 做图与分层标注；或打开 **Teleprompter** 编辑文稿再 **Play** 跟读（可与录制搭配）。

更多细节（分辨率、截图预设、图层、权限与故障排除）从下一节起按功能展开。

---

## 一、界面概览

主界面分为三部分：

1. **左侧预览区** — 实时显示录屏/会议画面，可叠加摄像头、白板、提词器
2. **顶部控制栏** — Capture Screen、Camera、Record、Live Meeting、Teleprompter 等
3. **右侧边栏** — 白板、摄像头设置、录制参数、美颜等

---

## 二、功能详解

### 2.1 屏幕捕获（Capture Screen）

**功能**：选择要录制的显示器整屏或单个窗口。

**操作**：
1. 点击 **Capture Screen**
2. **Electron 桌面版**：应用内会弹出选取列表，区分**整台显示器**与**单个窗口**（按提示选择即可）。**仅浏览器中打开**时，使用浏览器自带的屏幕共享选取界面。
3. 选择后预览区会显示共享内容
4. 录制中可点击 **Stop sharing** 停止共享

**适用**：录屏、会议屏幕共享、演示。

**注意**：macOS 必须在 **系统设置 → 隐私与安全性 → 屏幕录制** 中为当前运行的应用授权——开发调试时一般为 **Electron**，使用已打包的 `.app` 时为 **DreamWorks**。改权限后若选取器异常，可**完全退出并重新打开**应用再试。

---

### 2.2 摄像头（Start Camera）

**功能**：开启圆形画中画摄像头，可拖拽定位。

**操作**：
1. 点击 **Start Camera**
2. 摄像头画面以圆形显示在预览区
3. 拖拽可调整位置（四角：左上、右上、左下、右下）
4. 点击 **Stop Camera** 关闭

**设置**（右侧边栏 Video 区域）：
- **Size**：32–280px，调节画中画大小
- **Shape**：Circle（圆形）或 Landscape（横条）
- **Decor**：None / Simple / Glow / Dashed（边框样式）
- **Effect**：无 / 墨镜 / 趣味滤镜（🐞🩷）
- **Beauty**：美颜开关，可调磨皮、提亮、对比度等

**适用**：录课、直播、会议出镜。

**macOS 摄像头设置说明**：DreamWorks 使用 Web 标准 `getUserMedia` 调用摄像头。macOS 菜单栏的「视频」菜单（背景、人像模式等）由系统控制，通常仅对使用原生 AVFoundation 的应用（如 FaceTime、Zoom）显示。Electron 应用使用 Chromium 的摄像头管线，可能不会触发该菜单。若需虚拟背景，可使用 DreamWorks 内置的美颜与滤镜，或通过系统「照片」/「视频效果」在系统层面设置。

---

### 2.3 白板（Whiteboard）

**功能**：基于 Excalidraw 的绘图白板，支持多项目、多图层、纸张纹理。

#### 2.3.1 基本操作

- **绘图**：选择工具（矩形、箭头、自由绘制、文字等）在画布上绘制
- **选择**：点击元素可选中、移动、缩放、旋转
- **撤销**：主菜单 Undo，或两指点击（iPad/Sidecar）
- **重做**：主菜单 Redo

#### 2.3.2 项目（Project）

- 每个白板可有多个**项目**（类似多页文档）
- 主菜单 **Project** 可切换、新建、重命名、删除项目
- **Save as...**：另存为新项目

#### 2.3.3 图层（Layers）

- **Base**：底层永久内容（流程图、框架图等）
- **Annotation 1, 2, 3...**：可新建多个注释层，用于临时涂画
- **Layers...**：打开图层面板
  - 小眼睛：显示/隐藏该层
  - 点击图层名：切换当前绘制层
  - 垃圾桶：删除该注释层（Base 不可删）
- **New annotation layer**：新建注释层

**典型用法**：在 Base 层画好固定内容，讲解时新建 Annotation 层涂画，讲完可删除注释层保留 Base。

#### 2.3.4 纸张纹理（Paper texture）

- 主菜单 **Paper texture → Choose texture...**
- 可选：无、多种纸张纹理、 glitter 等
- 纹理会随项目保存

#### 2.3.5 iPad / Sidecar 手势

- **两指点击**：撤销（Undo）
- **三指点击**：显示/隐藏快捷栏（Undo、Redo、Clear）
- **两指横滑**（触控板）：撤销

#### 2.3.6 导入导出

- **Open**：打开 `.excalidraw` 或 `.json` 文件
- **Save to...**：保存为 `.excalidraw` 文件
- **Export...**：导出为 Excalidraw 格式
- **Export image...**：导出为 PNG 图片

**适用**：画流程图、会议标注、教学板书、产品草图。

---

### 2.4 录制（Record）

**功能**：将屏幕 + 摄像头 + 白板合成为视频，保存为 WebM 或 MP4。

**操作**：
1. 先 **Capture Screen** 或 **Start Camera**（至少其一）
2. 点击 **Start Recording**
3. 录制中可 **Pause** / **Resume**
4. 点击 **Stop** 结束
5. 选择保存路径，导出 WebM 或 MP4

**设置**（右侧边栏）：
- **Resolution**：1080p / 2K / 4K
- **Letterbox**：黑边或自定义背景（横竖屏不一致时）

**适用**：课程录制、演示视频、会议存档。

---

### 2.5 截图（Capture）

**功能**：截取当前预览画面为 PNG 图片。

**操作**：
1. 点击 **Capture** 按钮旁的下拉箭头
2. 选择模式：
   - **Preview (2K)**：整屏 2K 分辨率
3. 或选择预设尺寸（居中裁剪）：
   - Avatar 400×400
   - Background 1000×800
   - Cover vertical 1242×1660
   - Cover square 1080×1080
   - Cover horizontal 1200×900
   - Video cover vertical 1080×1440
   - Video cover horizontal 1440×1080 / 1920×1080

**适用**：封面图、头像、社交媒体配图。

---

### 2.6 提词器（Teleprompter）

**功能**：在预览区显示滚动提词稿，适合演讲、录课。

**操作**：
1. 录制时点击 **Teleprompter** 打开
2. 在右侧面板编辑文稿
3. 点击 **Play** 开始滚动，**Pause** 暂停
4. 可调速度、字号、透明度、宽度
5. 可拖拽提词器位置，**Near camera** 可贴近摄像头
6. **Save as**：保存为新文稿、下载 .md / .txt

**多文稿**：可新建、切换多个提词稿。

**适用**：录课、直播、演讲、口播视频。

---

### 2.7 在线会议（Live Meeting）

**功能**：WebRTC 视频会议，支持音视频、屏幕共享、聊天、会议录制、虚拟背景、实时转录。

#### 2.7.1 加入会议

1. 点击 **Live Meeting**
2. 输入昵称、房间号
3. 选择模式：**Cloud**（云端信令）或 **Local**（局域网）
4. 点击 **Join**

#### 2.7.2 创建会议（Local 局域网模式）

1. 选择 **Local** 模式
2. 选择 **Host**，点击 **Create room**
3. 应用会生成房间地址（如 `http://192.168.x.x:3001`）
4. 分享该地址给同一 Wi-Fi 下的参与者
5. 参与者选择 **Join**，输入地址加入

**优势**：无需云服务器、无订阅费、低延迟、数据不出内网。

#### 2.7.3 会议内功能

- **麦克风 / 摄像头**：静音、关闭视频
- **屏幕共享**：共享当前屏幕
- **聊天**：文字消息
- **录制**：会议内录制
- **虚拟背景**：模糊、纯色
- **实时转录**：语音转文字（需浏览器支持）
- **视图**：Gallery（宫格）或 Speaker（主讲人）

**适用**：团队会议、远程协作、内网培训。

---

### 2.8 其他设置

#### 预览位置

- 摄像头画中画可放置在：左上、右上、左下、右下

#### 美颜（Beauty）

- 磨皮、提亮、柔光、美白、对比度、饱和度
- 可选用预设或自定义

#### 音频

- **Mic volume**：麦克风音量
- **System volume**：系统音（录屏时是否录入系统声音）

## 四、数据存储

- **设置**：保存在本地。Electron 下为应用数据目录中的 `settings.json`（macOS 常见路径：`~/Library/Application Support/DreamWorks/`）；若你曾用过旧版目录名 `dreamwork`，应用会在适当时机**自动迁移**到 `DreamWorks`。纯浏览器访问时使用 **localStorage**，与桌面版数据不互通。
- **白板**：每个项目自动保存，含图层、纹理、元素
- **提词稿**：多文稿保存在设置中
- **录制文件**：保存至用户选择的路径

打包后的 `.app` 不会把你的白板/提词稿「打进包内」；若发现数据「丢失」，先确认是否混用了浏览器版与 Electron 版，或参见仓库 `README` 与 `defaults/README.md` 中的说明。

## 六、故障排除

| 问题 | 处理 |
|-----|------|
| Capture Screen 无效 / 选不到整屏 | 系统设置 → 隐私与安全性 → 屏幕录制 → 对**当前实际在跑的应用**开启（`npm run dev` 时为 **Electron**，打包应用为 **DreamWorks**）；改完后**退出并重开**应用。列表里若同时有相似名称，可暂时都打开试排错。 |
| 摄像头不显示 | 检查系统摄像头权限 |
| 会议无法连接 | 检查网络；Local 模式确认同一 Wi-Fi |
| 白板 Undo 无效 | 先点击白板区域获得焦点，再试手势或菜单 |
| 打包后白板/提词稿不见了 | 数据在用户目录的 `Application Support`，不是 `.app` 内部；勿只用浏览器版却期待桌面版同一份文件。详见上文「四、数据存储」。 |
